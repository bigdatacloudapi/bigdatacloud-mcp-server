How to read a verdict. urlscan.io only knows about URLs somebody submitted to it. A name with no scans is not vouched for — it has no public history, which is the normal state for first-party telemetry. Threat verdicts come from submitter tags, not from verdicts.overall.malicious: that field is gated below a Pro plan and reads false even on scans a submitter tagged as phishing, so anything built on it would call everything clean.
